# Sistema Único de Información - Residencial Los Robles

Este repositorio contiene la maquetación y desarrollo del prototipo para el **Sistema Único de Información del Residencial Los Robles**, creado como parte del proyecto integrador de la materia **Proyecto II** en la **Licenciatura en Desarrollo Web** de la **Universidad de Guadalajara (UDG Virtual / UDG+)**.

---

## Descripción del Proyecto

El proyecto aplica la metodología ágil **Scrum** para el desarrollo de una plataforma web responsiva diseñada para optimizar la gestión administrativa y la comunicación entre los colonos, la Mesa Directiva y el personal de mantenimiento de la comunidad.

### Historias de Usuario Desarrolladas (Product Backlog)
- **HU-01:** Consulta de estados de cuenta y validación de pagos en línea (*En progreso*).
- **HU-02:** Módulo de votaciones digitales con regla de 1 voto por propiedad (*Planificado - Sprint 2*).
- **HU-03:** Reporte de incidencias y emergencias con evidencia fotográfica (*Planificado - Sprint 2*).
- **HU-04:** Gestión de perfiles, usuarios y control de seguridad por roles (*Finalizado*).
- **HU-05:** Interfaz gráfica adaptativa y responsiva para móviles y escritorio (*Finalizado*).

---

## Tecnologías Utilizadas

- **Frontend:** React.js, HTML5, CSS3 (Diseño responsivo), JavaScript (ES6+).
- **Herramientas de Construcción:** Vite.
- **Gestión del Proyecto (Agile):** Jira Software, Scrum Framework, Git & GitHub.
